# Dhaka Tesla Pool - Requirements

## 1. Overview

Dhaka Tesla Pool is a ride-pooling MVP where multiple passengers can
share a Tesla when their routes are compatible.

The system has three main actors:

- Passenger
- Driver
- Pool/Ride

## 2. Demo Users

### Driver

### Passengers

## 3. Passenger Features

- Register
- Login
- Request a ride
- Select pickup area
- Select destination area
- Select number of seats
- View estimated fare
- View ride status
- Cancel a valid ride
- View ride history

## 4. Driver Features

- Login
- Go online/offline
- View relevant ride requests
- Accept a ride/pool
- Mark driver as arrived
- Start trip
- Complete trip
- View passengers and occupied seats
- View ride history

## 5. Pool Features

- Multiple passengers can share one vehicle
- Vehicle capacity must never be exceeded
- Each passenger has an individual fare
- Pool membership is tracked
- Ride lifecycle is enforced
- Ride history is preserved
